# Josephson junctions & superconducting circuits

Численные модели джозефсоновских переходов и топология сверхпроводниковых схем.

**Python · NumPy · SciPy · Matplotlib · KLayout · Ruby**

## Проекты

| Проект | Что внутри |

| [LJJ + JTL](https://github.com/asfdqyz/long-josephson-junction-jtl) | Ёмкостная связь длинного перехода и JTL, SFQ-импульсы, ВАХ, спектры |
| [Топология LJJ](https://github.com/asfdqyz/long-josephson-junction-chip) | Топология длинных переходов 1000/1200/1400 мкм, результаты моделирования|
| [Флюксоны](https://github.com/asfdqyz/long-josephson-junction-fluxons) | Ступени нулевого поля, ВАХ длинного перехода|
| [Магнитное поле](https://github.com/asfdqyz/long-josephson-junction-field) | Ступени Фиске, ВАХ длинного перехода |
| [LC-резонатор](https://github.com/asfdqyz/josephson-lc-resonator) | Переход с резонатором: ВАХ и спектры|
| [Тестовая топология](https://github.com/asfdqyz/test-chip-layout) | Первый опыт с топологией |
